# Version 0.0.11

## Added
- Added the ability to add item tags to the whitelist! 
  - Use the format of #namespace:location. 
  - Example: #minecraft:clonable_maps will contain all filled maps and structure maps.
- Added all explorer and abandoned camp structure maps to the default whitelist config.
- Added the Compass, Lodestone Compass and Clock to the default whitelist config.

Note: Applying these new default config options on an existing Minecraft instance requires deleting the config file to regenerate it.
(Default config file location: .minecraft\config\boatiview\client.toml)
